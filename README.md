# Remix of Sathi Community Support

We are building sathi AI.

This is a hackathon prototype for a

digital public assistance platform in Pakistan.

Target users:

1. Citizens with low digital literacy.

2. Community helpers managing families.

3. Government department officers.

4. Administrators.

For this first stage, build ONLY the

frontend UI using mock data.

Create:

1. A professional landing page.

2. Login page with role selection for demo.

3. Citizen dashboard.

4. Community helper dashboard.

5. Officer dashboard.

Design:

- Premium professional SaaS interface.

- Navy blue, white and subtle gold.

- Mobile responsive.

- Simple English and Urdu-friendly layout.

- Large buttons and accessible typography.

Important:

- Do not connect any real government API.

- Do not use real personal data.

- Clearly label the application as a prototype.

- Use synthetic demo records only.

- Make navigation functional.

- Do not implement backend yet.

- Do not add unnecessary features.

Build a clean and consistent application.
